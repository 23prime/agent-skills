# スキルスクリプトのリンク

このリポジトリの `skills/*/scripts/*.sh` を全て、`$PATH` の通ったディレクトリに
`as-<スクリプト名>`（`.sh` 拡張子なし、フラットな名前空間）としてシンボリック
リンクする。バンドルスクリプトのファイル名は kebab-case であり、プレフィックス
以外は `as-` リンク名と一致する。再実行しても安全：既存リンクを更新し、この
リポジトリを指しているがリンク元スクリプトが存在しなくなった不要なリンクを
削除する。他を指している `as-*` エントリには一切触れない。

## ワークフロー

### 1. 配置先ディレクトリを決める

配置先をユーザーに確認する。デフォルトは `~/.local/bin`。

### 2. スクリプトを実行する

```bash
skills/linking-skill-scripts/scripts/link-scripts.sh <配置先>
```

`<配置先>` を省略するとデフォルト（`~/.local/bin`）を使う。

### 3. 結果を報告する

スクリプトの出力からリンク・削除内容を要約する。`warning: ... is not on
your PATH ...` という行が出力されていれば、配置先ディレクトリをシェルの
プロファイルに追加するようユーザーに伝える。例：

```bash
export PATH="<配置先>:$PATH"
```

## 注意事項

- `skills/*/scripts/*.sh` に変更（新規スクリプト、リネーム、削除）があるたびに
  このスキルを再実行する。冪等である。
- このリポジトリに解決されるシンボリックリンクのみを作成・削除する。配置先に
  既にある無関係な `as-*` コマンドには触れない。
