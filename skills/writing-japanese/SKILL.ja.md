# 日本語の文章を書く

句読点・半角全角の使い分け・カタカナ語の表記を一貫させて、日本語の技術文章を書く。

## ルール

### 句読点

- 原則として文末に句点を付ける。箇条書きや表のセルも例外ではない。
- 体言止め（名詞の羅列など、完全な文になっていない行）の場合は句点を省略する。
- 一文はできるだけ短く保つ。読点の打ち方に決まったルールはない。
- 同一の箇条書き・表の中では、文末表現を統一する。すべて体言止めにするか、すべて句点付きの完全な文にするかのいずれかとし、両者を混在させない。

### 文体

- リポジトリ内の同種の文書では、です・ます調かだ・である調のいずれかに統一する。同じ種類の文書内で両者を混在させない。

### 分かち書き（日本語と英数字の間のスペース）

- 日本語と半角英数字が隣接する箇所には、原則としてスペースを入れる。

### 半角・全角

| 対象 | ルール |
| --- | --- |
| 英数字 | 半角とする。 |
| 英数字に付随する記号（区切り文字 `-` `_` `+`、単位 `$` `%`、パス `/` `\`、その他 `#` `@` `&` `=` `~` `^` `\|` `<` `>`） | 半角とする。 |
| コードブロック・インラインコード内の記号 | すべて半角（そのまま）とする。 |
| 日本語文中の句読点・括弧（`！` `？` `：` `；` `（）` `「」` `【】` `『』` `…`） | 全角とする。箇条書きのラベルに付くコロンなどの短い断片も対象（例：`あり：サーバー`であり`あり: サーバー`ではない）。 |
| 日本語文中の引用 | `「」` を使う（`"` `'` は使わない）。 |
| ダッシュ | 原則使わない。どうしても必要な場合は半角 `--` を使う。 |
| 範囲を示す波線 | 全角 `〜` を使う。 |

### カタカナ語

[外来語の表記 留意事項その2（文化庁）](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/gairai/honbun06.html) に準拠する。

- 長音は原則として長音符号「ー」を用いて書く。
- 英語の語末 -er / -or / -ar に当たるものは原則としてア列の長音とし「ー」を用いる。ただし慣用に応じて省くことができる。
  - 「ー」あり：サーバー、ユーザー、メンテナー、コンピューター、エレベーター
  - 慣用により「ー」なし：コンテナ、ディレクトリ、フォルダ

## レビュー時のチェックリスト

既存の日本語文章をレビューする際は、次の順に確認する。

1. 文末に句点があり、体言止めの行では正しく省略されているか。
2. 一文が短く保たれているか。
3. 同一の箇条書き・表の中で、文末表現（体言止めか句点付きの完全な文か）が統一されているか。
4. リポジトリ内の同種の文書で、です・ます調かだ・である調が統一されているか。
5. 日本語と英数字の間にスペースがあるか。
6. 半角・全角の使い分けが上記の表と一致しているか。
7. カタカナ語が長音表記のルールに従っているか。
